# Ko'kcha Eshiklar Premium

Premium MDF eshiklar sayti (UZ / RU / EN). Oddiy statik sayt — build kerak emas.

- `index.html`, `katalog.html`, `mahsulot.html`, `ishlarimiz.html`, `biz-haqimizda.html`, `aloqa.html` — sahifalar
- `assets/js/data.js` — kontaktlar, mahsulotlar, portfolio, Supabase sozlamalari
- `assets/js/i18n.js` — tarjimalar
- `assets/img/` — rasmlar (qaysi rasm qayerga: `assets/img/RASMLAR.txt`)

Arizalar Supabase'dagi `kokcha_arizalar` jadvaliga tushadi.
Sayt Netlify'da GitHub'dan avtomatik joylanadi: `main` branchga push qilinsa, sayt yangilanadi.
